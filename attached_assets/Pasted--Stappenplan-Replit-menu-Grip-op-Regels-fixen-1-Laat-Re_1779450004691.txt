## Stappenplan Replit — menu “Grip op Regels” fixen

### 1. Laat Replit eerst zoeken

Open **Replit Agent** en plak:

```txt
Zoek in het hele project naar deze teksten:

"Brief analyseren"
"Regelcheck"
"WOO-verzoek"
"Regelgeving"

Laat zien in welke bestanden deze menu-items staan.
Pas nog niets aan.
```

---

### 2. Menu-items vervangen

Daarna plak je:

```txt
Vervang binnen de navigatie van "Grip op Regels" deze oude menu-items:

- Brief analyseren
- Regelcheck
- WOO-verzoek
- Regelgeving

Door exact deze drie nieuwe items:

- Sectorregels
- Wat komt eraan?
- Documenten opvragen

Deze moeten zichtbaar worden in de sidebar, het dashboardmenu en op de pagina Grip op Regels.
```

---

### 3. Routes goed zetten

Gebruik deze routes:

```txt
/regels/sectorregels
/regels/wat-komt-eraan
/regels/documenten-opvragen
```

Oude routes mogen blijven bestaan, maar moeten doorverwijzen naar de nieuwe structuur.

---

### 4. Hoofdkaarten maken

Laat Replit daarna dit doen:

```txt
Maak op de pagina "Grip op Regels" drie hoofdkaarten:

1. Sectorregels
Tekst:
"Bekijk welke regels gelden voor jouw sector, per gemeente, en wat de impact is op kosten, verplichtingen, risico's en kansen."

2. Wat komt eraan?
Tekst:
"Volg aankomende wijzigingen zoals Digital ID, AI Act, AVG, Omgevingswet, subsidies en gemeentelijke besluiten."

3. Documenten opvragen
Tekst:
"Stel je vraag of upload een brief. OpenRegio maakt er een AVG-controleslag of WOO-verzoek van met conceptbrief."
```

---

### 5. Gemeente-update toevoegen bij Sectorregels

```txt
Voeg bij Sectorregels toe:

"OpenRegio volgt regelgeving per gemeente en werkt wijzigingen door in sectorinformatie."

Toon velden:

- Gemeente
- Sector
- Laatste wijziging
- Impact
- Actie nodig
```

---

### 6. Testen

In Replit Shell:

```bash
npm run check
npm run dev
```

Test daarna:

```txt
/regels
/regels/sectorregels
/regels/wat-komt-eraan
/regels/documenten-opvragen
```

---

### 7. Als menu niet verandert

Dan deze opdracht geven:

```txt
De pagina is aangepast, maar de sidebar/menu-items zijn nog oud.

Zoek specifiek in:

client/src/components
client/src/layout
client/src/config
client/src/pages

naar:
"Brief analyseren"
"Regelcheck"
"WOO-verzoek"
"Regelgeving"

Vervang deze hardcoded menu-items overal door:

"Sectorregels"
"Wat komt eraan?"
"Documenten opvragen"
```

Dit is de juiste fix-route. Replit moet niet alleen de pagina aanpassen, maar vooral de **navigatiebestanden**.
