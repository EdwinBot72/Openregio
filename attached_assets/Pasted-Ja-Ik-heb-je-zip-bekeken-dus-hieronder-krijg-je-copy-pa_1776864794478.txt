## 3) `client/src/App.tsx`

Dit bestand is groot. Dus hier is de **gerichte aanpassing** die je moet doen in je bestaande `AuthenticatedRouter()`.

### A) Vervang deze redirects:

Zoek dit stuk:

```tsx
<Route path="/kansen">
  <Redirect to="/kansen/opdrachten" />
</Route>
<Route path="/regels">
  <Redirect to="/regels/updates" />
</Route>
<Route path="/groei">
  <Redirect to="/groei/profiel" />
</Route>
<Route path="/account">
  <Redirect to="/account/instellingen" />
</Route>
```

Vervang door:

```tsx
<Route path="/kansen">
  <Redirect to="/kansen/opdrachten" />
</Route>
<Route path="/regels">
  <Redirect to="/regels/updates" />
</Route>
<Route path="/groei">
  <Redirect to="/groei/profiel" />
</Route>
<Route path="/account">
  <Redirect to="/account/instellingen" />
</Route>
```

Die kan dus blijven zoals hij is.

### B) Belangrijk: vervang je hele Vandaag-sectie

Zoek dit:

```tsx
{/* ── Vandaag (Sectie 1) ─────────────────────────────────────────────── */}
<Route path="/vandaag" component={VandaagPage} />
<Route path="/vandaag/updates" component={IntelPage} />
<Route path="/vandaag/acties" component={CursussenPage} />
<Route path="/vandaag/samen" component={SamenAanpakkenPage} />
<Route path="/vandaag/nieuws" component={NieuwsPage} />
```

Vervang door:

```tsx
{/* ── Vandaag (compact dashboard) ───────────────────────────────────── */}
<Route path="/vandaag" component={VandaagPage} />

{/* oude submenu-routes van Vandaag terug naar 1 dashboard */}
<Route path="/vandaag/updates">
  <Redirect to="/vandaag" />
</Route>
<Route path="/vandaag/acties">
  <Redirect to="/vandaag" />
</Route>
<Route path="/vandaag/samen">
  <Redirect to="/vandaag" />
</Route>
<Route path="/vandaag/nieuws">
  <Redirect to="/vandaag" />
</Route>
```

## 4) Extra schoonmaak in `App.tsx`

Deze imports gebruik je dan waarschijnlijk niet meer:

```tsx
import NieuwsPage from "@/pages/nieuws";
import SamenAanpakkenPage from "@/pages/samen-aanpakken";
import CursussenPage from "@/pages/cursussen";
```

Als TypeScript klaagt dat ze unused zijn: **weghalen**.

`IntelPage` blijft wel nodig, want die gebruik je nog bij `/regels/updates`.
