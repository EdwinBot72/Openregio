Ja. Hieronder staat een **Replit-ready codeblok** waarmee je:

* **Basis op €19 ex btw**
* **Pro op €49 ex btw**
* affiliate commissie zet op:

  * **Basis: 25% eerste 3 maanden**
  * **Pro: 35% eerste 3 maanden**

Ik maak het expres modulair, zodat je dit in je app kunt hangen voor pricing, affiliate-berekening en checkout-logica.

```ts
// pricing.ts
// OpenRegio pricing + affiliate model

export type PlanKey = "basis" | "pro";

export interface PlanConfig {
  key: PlanKey;
  name: string;
  priceExVatMonthly: number;
  affiliatePercent: number; // percentage over eerste 3 maanden
  affiliateMonths: number;
}

export const PRICING: Record<PlanKey, PlanConfig> = {
  basis: {
    key: "basis",
    name: "Basis",
    priceExVatMonthly: 19,
    affiliatePercent: 25,
    affiliateMonths: 3,
  },
  pro: {
    key: "pro",
    name: "Pro",
    priceExVatMonthly: 49,
    affiliatePercent: 35,
    affiliateMonths: 3,
  },
};

export interface AffiliatePayoutResult {
  plan: PlanKey;
  monthlyPriceExVat: number;
  affiliatePercent: number;
  affiliateMonths: number;
  payoutPerMonthExVat: number;
  totalPayoutExVat: number;
}

export function calculateAffiliatePayout(plan: PlanKey): AffiliatePayoutResult {
  const config = PRICING[plan];
  const payoutPerMonthExVat =
    (config.priceExVatMonthly * config.affiliatePercent) / 100;

  const totalPayoutExVat = payoutPerMonthExVat * config.affiliateMonths;

  return {
    plan,
    monthlyPriceExVat: config.priceExVatMonthly,
    affiliatePercent: config.affiliatePercent,
    affiliateMonths: config.affiliateMonths,
    payoutPerMonthExVat: Number(payoutPerMonthExVat.toFixed(2)),
    totalPayoutExVat: Number(totalPayoutExVat.toFixed(2)),
  };
}

export function getPlanPrice(plan: PlanKey): number {
  return PRICING[plan].priceExVatMonthly;
}
```

## Voorbeeld gebruik in backend

```ts
// example-usage.ts

import { calculateAffiliatePayout, getPlanPrice, PlanKey } from "./pricing";

const proPrice = getPlanPrice("pro");

console.log("Pro prijs ex btw:", proPrice); // 49

```

## Als je affiliate-records opslaat in database

```ts
// affiliate.ts

import { PlanKey, calculateAffiliatePayout } from "./pricing";

export interface AffiliateConversionInput {
  affiliateId: string;
  customerId: string;
  selectedPlan: PlanKey;
}

export interface AffiliateConversionRecord {
  affiliateId: string;
  customerId: string;
  plan: PlanKey;
  monthlyPriceExVat: number;
  affiliatePercent: number;
  affiliateMonths: number;
  payoutPerMonthExVat: number;
  totalPayoutExVat: number;
  status: "pending" | "approved" | "paid" | "rejected";
}

export function createAffiliateConversionRecord(
  input: AffiliateConversionInput
): AffiliateConversionRecord {
  const payout = calculateAffiliatePayout(input.selectedPlan);

  return {
    affiliateId: input.affiliateId,
    customerId: input.customerId,
    plan: input.selectedPlan,
    monthlyPriceExVat: payout.monthlyPriceExVat,
    affiliatePercent: payout.affiliatePercent,
    affiliateMonths: payout.affiliateMonths,
    payoutPerMonthExVat: payout.payoutPerMonthExVat,
    totalPayoutExVat: payout.totalPayoutExVat,
    status: "pending",
  };
}
```

## Als je ook BTW wilt tonen op frontend

```ts
export function addVat(amountExVat: number, vatRate = 21): number {
  return Number((amountExVat * (1 + vatRate / 100)).toFixed(2));
}

// voorbeeld:
const basisInclVat = addVat(19); // 22.99
const proInclVat = addVat(49);   // 59.29
```

## Nog simpeler, als je alleen 1 blok wilt plakken

```ts
const pricing = {
  basis: {
    name: "Basis",
    monthlyPriceExVat: 19,
    affiliatePercent: 25,
    affiliateMonths: 3,
  },
  pro: {
    name: "Pro",
    monthlyPriceExVat: 49,
    affiliatePercent: 35,
    affiliateMonths: 3,
  },
};

function affiliateTotal(plan: "basis" | "pro") {
  const p = pricing[plan];
  const perMonth = (p.monthlyPriceExVat * p.affiliatePercent) / 100;
  const total = perMonth * p.affiliateMonths;

  return {
    plan: p.name,
    priceExVat: p.monthlyPriceExVat,
    affiliatePercent: p.affiliatePercent,
    payoutPerMonthExVat: Number(perMonth.toFixed(2)),
    totalPayoutExVat: Number(total.toFixed(2)),
  };
}

console.log(affiliateTotal("basis"));
// payoutPerMonthExVat: 4.75
// totalPayoutExVat: 14.25

console.log(affiliateTotal("pro"));
// payoutPerMonthExVat: 17.15
// totalPayoutExVat: 51.45
```

## Dit zijn de exacte uitkomsten

* **Basis €19** → 25% = **€4,75 p/m** → 3 maanden = **€14,25**
* **Pro €49** → 35% = **€17,15 p/m** → 3 maanden = **€51,45**

Als je wil, zet ik dit in de **exacte structuur van jouw OpenRegio project** met:

* `shared/pricing.ts`
* `server/affiliate.ts`
* `client/src/lib/plans.ts`

zodat je het bijna 1-op-1 kunt plakken.
