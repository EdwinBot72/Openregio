# 1) SERVER: dossier-context kunnen ophalen

## A) Maak een “dossier context builder”

In `server/regiobot.js` (of waar je DB-pool zit), voeg dit toe:

```js
async function fetchDossierContextByRequestId(requestId) {
  const client = await pool.connect();
  try {
    const req = await client.query(
      `select r.id, r.title, r.body, r.reference_code, r.sent_at, r.status,
              rg.slug as region_slug, rg.name as region_name,
              au.slug as authority_slug, au.name as authority_name,
              r.category_slug
       from woo_requests r
       left join regions rg on rg.id = r.region_id
       left join authorities au on au.id = r.authority_id
       where r.id = $1`,
      [requestId]
    );

    if (!req.rows[0]) return null;

    const docs = await client.query(
      `select id, kind, filename, file_url, received_at, summary, text_content, category_slug
       from woo_documents
       where request_id = $1
       order by coalesce(received_at, created_at) asc`,
      [requestId]
    );

    const r = req.rows[0];

    const header = [
      `DOSSIER`,
      `request_id: ${r.id}`,
      r.title ? `title: ${r.title}` : null,
      r.region_slug ? `region: ${r.region_slug}` : null,
      r.authority_slug ? `authority: ${r.authority_slug}` : null,
      r.reference_code ? `kenmerk: ${r.reference_code}` : null,
      r.sent_at ? `sent_at: ${r.sent_at}` : null,
      r.status ? `status: ${r.status}` : null,
      r.category_slug ? `category: ${r.category_slug}` : null,
    ].filter(Boolean).join("\n");

    const reqBody = r.body ? `REQUEST_BODY:\n${compact(r.body, 2500)}` : "";

    const docBlocks = docs.rows.map((d, i) => {
      const meta = [
        `DOC ${i + 1}`,
        `document_id: ${d.id}`,
        d.kind ? `kind: ${d.kind}` : null,
        d.received_at ? `received_at: ${d.received_at}` : null,
        d.filename ? `filename: ${d.filename}` : null,
        d.file_url ? `file_url: ${d.file_url}` : null,
        d.category_slug ? `category: ${d.category_slug}` : null,
      ].filter(Boolean).join("\n");

      const content = [
        d.summary ? `summary: ${compact(d.summary, 900)}` : null,
        d.text_content ? `text: ${compact(d.text_content, 1800)}` : null,
      ].filter(Boolean).join("\n");

      return `${meta}\n${content}`.trim();
    }).join("\n\n");

    return `${header}\n\n${reqBody}\n\n${docBlocks}`.trim();
  } finally {
    client.release();
  }
}
```

## B) Laat `/api/regiobot` ook `dossierRequestId` accepteren

In jouw `RegioBotInput` schema:

```js
dossierRequestId: z.number().int().positive().optional(),
```

En in `runRegioBot()` vóór je sourcesText opbouwt:

```js
let dossierContext = null;
if (input.dossierRequestId) {
  dossierContext = await fetchDossierContextByRequestId(input.dossierRequestId);
}
```

En voeg in `messages` een extra blok toe (na taskInstruction, vóór bronnen):

```js
if (dossierContext) {
  messages.push({
    role: "user",
    content: `DOSSIER CONTEXT (geselecteerd):\n\n${dossierContext}`
  });
}
```

✅ Resultaat: RegioBot kan nu “in dossier werken” zonder paste.

# 2) SERVER: endpoints om dossiers te kiezen in de UI

## A) Lijst dossiers (minimaal)

Maak in je server routes:

### `GET /api/woo/dossiers`

```js
app.get("/api/woo/dossiers", async (req, res) => {
  const client = await pool.connect();
  try {
    const rows = await client.query(`
      select r.id, r.title, r.reference_code, r.sent_at, r.status,
             rg.slug as region_slug, rg.name as region_name,
             au.slug as authority_slug, au.name as authority_name
      from woo_requests r
      left join regions rg on rg.id = r.region_id
      left join authorities au on au.id = r.authority_id
      order by coalesce(r.sent_at, r.created_at) desc
      limit 200
    `);
    res.json(rows.rows);
  } catch (e) {
    res.status(500).json({ error: "dossiers_list_failed" });
  } finally {
    client.release();
  }
});
```

Optioneel later: filters `?region=...&authority=...`.

# 3) CLIENT: dossier selector in RegioBot pagina

In je `client/src/pages/regiobot.tsx`:

## A) Voeg query toe

Bovenin:

```ts
interface DossierRow {
  id: number;
  title: string;
  reference_code: string | null;
  sent_at: string | null;
  status: string | null;
  region_slug: string | null;
  region_name: string | null;
  authority_slug: string | null;
  authority_name: string | null;
}
```

En in component:

```ts
const { data: dossiers = [] } = useQuery<DossierRow[]>({ queryKey: ["/api/woo/dossiers"] });
const [selectedDossierId, setSelectedDossierId] = useState<string>("none");
```

## B) Stop dossierId in payload

In je `payload`:

```ts
dossierRequestId: selectedDossierId === "none" ? undefined : Number(selectedDossierId),
```

## C) Voeg dropdown toe boven input (zelfde layout)

Plaats dit bij je regio/authority selects:

```tsx
<div className="space-y-1 md:col-span-2">
  <div className="text-xs text-muted-foreground">Dossier (optioneel)</div>
  <Select value={selectedDossierId} onValueChange={setSelectedDossierId}>
    <SelectTrigger>
      <SelectValue placeholder="Kies dossier" />
    </SelectTrigger>
    <SelectContent>
      <SelectItem value="none">Geen dossier (losse vraag)</SelectItem>
      {dossiers.map((d) => (
        <SelectItem key={d.id} value={String(d.id)}>
          {d.title} {d.reference_code ? `• ${d.reference_code}` : ""} {d.region_name ? `• ${d.region_name}` : ""}
        </SelectItem>
      ))}
    </SelectContent>
  </Select>
  <p className="text-[10px] text-muted-foreground">
    Met dossier geselecteerd: RegioBot gebruikt automatisch verzoek + bijlagen als context.
  </p>
</div>
```

✅ Nu: klik dossier → klik task → “Verwerk” → output.

# 4) BONUS: “Run in RegioBot” knop op dossier detailpagina

Als je een dossier detail page hebt (bijv. `/woo/:id`), voeg een knop toe:

* Button: **“Open in RegioBot”**
* Link naar `/regiobot?dossier=<id>`

En in RegioBot page: lees query param en zet `selectedDossierId` automatisch.

Pseudo:

```ts
const params = new URLSearchParams(window.location.search);
const dossier = params.get("dossier");
useEffect(() => { if (dossier) setSelectedDossierId(dossier); }, []);
```

## Wat je nu hebt (echt)

* RegioBot is **task-based**
* RegioBot is **dossier-aware**
* Geen copy/paste meer
* Output blijft: analyse + ontbreekt + vervolg-WOO + bronnen
* Geen boete/traffic ruis (blijft geblokt)

Als je wil, pak ik als volgende stap:
**“dossier context slim maken”** → alleen de *meest relevante* docs selecteren (top 3) i.p.v. alles dumpen. Dat scheelt tokens en maakt antwoorden strakker.
