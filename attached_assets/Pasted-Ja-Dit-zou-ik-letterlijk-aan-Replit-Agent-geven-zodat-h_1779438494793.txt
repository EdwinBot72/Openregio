# OpenRegio – Grip op Regels 2.0

## Doel

Maak van "Grip op Regels" een praktische ondernemersmodule.

Geen juridisch jargon.

Ondernemers willen drie dingen weten:

1. Welke regels gelden voor mijn bedrijf?
2. Welke veranderingen komen eraan?
3. Hoe vraag ik documenten op of controleer ik een besluit?

De pagina moet voelen als een ondernemers-dashboard.

---

# Structuur

Maak drie hoofdkaarten.

```txt
┌─────────────────────────┐
│ Sectorregels            │
└─────────────────────────┘

┌─────────────────────────┐
│ Wat komt eraan?         │
└─────────────────────────┘

┌─────────────────────────┐
│ Documenten opvragen     │
└─────────────────────────┘
```

---

# Blok 1: Sectorregels

Titel:

```txt
Welke regels gelden voor jouw bedrijf?
```

Subtekst:

```txt
Bekijk direct welke vergunningen,
meldingen, verplichtingen en controles
voor jouw sector gelden.
```

Sectoren:

```txt
Horeca
Detailhandel
Techniek
Bouw
Agrarisch
Zorg & Welzijn
Dienstverlening
```

Per sector tonen:

```txt
Vergunningen

Belastingen

Gemeentelijke regels

Milieu-eisen

Personeel & veiligheid

Aankomende wijzigingen
```

Voorbeeldkaart:

```txt
Horeca

✓ Exploitatievergunning

✓ Terrasregels

✓ Alcoholwet

✓ Brandveiligheid

✓ Afvalverwerking

2 wijzigingen op komst
```

CTA:

```txt
Bekijk sector
```

Route:

```txt
/regels/sector/:id
```

# Blok 2: Wat komt eraan?

Titel:

```txt
Welke veranderingen komen eraan?
```

Subtekst:

```txt
Nieuwe wetten, subsidies,
Digital ID, Europese regels
en lokale ontwikkelingen.
```

Kaarten:

```txt
Digital Identity Wallet

AI Act

AVG wijzigingen

CSRD rapportage

Nieuwe subsidies

Gemeentelijke verordeningen

Milieuregels

Belastingwijzigingen
```

Per item tonen:

```txt
Wat verandert?

Wie raakt dit?

Wanneer?

Wat moet je doen?
```

Urgentie badges:

```txt
Nu actie nodig

Binnen 6 maanden

Volgend jaar

In onderzoek
```

Route:

```txt
/regels/ontwikkelingen
```

---

# Blok 3: Documenten opvragen

Titel:

```txt
Openbaar maken en controleren
```

Subtekst:

```txt
Stuur een vraag, brief of document.
OpenRegio maakt automatisch een
AVG-controleslag of WOO-verzoek.
```

Workflow visualiseren:

```txt
Vraag stellen

↓

AI analyse

↓

AVG controle
of
WOO verzoek

↓

Conceptbrief

↓

Menselijke controle

↓

Verzenden
```

Knoppen:

```txt
AVG-controleslag starten

WOO-verzoek maken

Document uploaden
```

Routes:

```txt
/regels/avg

/regels/woo

/regels/upload
```

# Design

Gebruik dezelfde stijl als de huidige OpenRegio dashboardkaarten:

```txt
grote iconen

duidelijke CTA's

maximaal 3 regels tekst

veel witruimte

mobiel eerst

geen juridische taal
```

Doel: een ondernemer moet binnen 10 seconden begrijpen:
**"Welke regels gelden voor mij, wat verandert er binnenkort en hoe vraag ik documenten op?"**
