Helder. Dan maken we het zo dat **het verdienmodel wel werkt, maar nergens op de site wordt uitgelegd**. De site voelt als een **open kennisplatform**, terwijl de tools automatisch naar **Pro** leiden.

Ik geef je hieronder een **kant-en-klaar plan + Replit prompt**.

---

# OpenRegio – Toolkit structuur (zonder verdienmodel zichtbaar)

## Kernbelofte op de site

Geen prijzen, geen verkooptaal.

Homepage / dashboard boodschap:

**“Begrijp regels, brieven en besluiten.”**

Subtekst:

> OpenRegio maakt regelgeving en brieven begrijpelijk voor ondernemers.
> Zie wie beslist, waarom, en wat je kunt doen.

---

# Gebruikersstructuur

## Basis gebruiker

Kan:

* dashboard bekijken
* regelgeving monitor bekijken
* voorbeeld briefanalyses lezen
* kennisbank gebruiken
* regio updates zien

Maar:

* geen upload
* geen persoonlijke analyse
* geen documentbibliotheek

---

## Pro gebruiker (onzichtbaar upsell)

Krijgt automatisch extra knoppen:

* document upload
* brief analyse
* informatie verzoek generator
* document opslag
* website check

De site zegt alleen:

**“Extra tools beschikbaar.”**

---

# Dashboard ontwerp (1 oogopslag)

Dit is het belangrijkste scherm.

Structuur:

```
------------------------------------------------
Hallo ondernemer

Wat wil je doen?
------------------------------------------------

[ Bekijk regels ] 
[ Analyseer een brief ]
[ Stel een vraag ]
```

---

# Dashboard blokken

## 1️⃣ Regels in jouw regio

Titel:

**Wat verandert er in jouw regio**

Lijst:

* herinrichting marktplein
* subsidie verduurzaming
* aanbesteding groen

Klik → uitleg.

---

## 2️⃣ Begrijp een brief

Titel:

**Hoe lees je een brief**

Voorbeeldanalyse:

```
Afzender
Gemeente Utrecht

Document type
Besluit

Juridische basis
Omgevingswet artikel ...

Termijn
Bezwaar mogelijk binnen 6 weken
```

Knop:

**Analyseer een document**

---

## 3️⃣ Vraag RegioBot

Titel:

**Vraag over regels of brieven**

Input:

```
Mag mijn terras groter?
Moet ik reageren op deze brief?
Welke subsidie bestaat er?
```

---

## 4️⃣ Digitale zichtbaarheid

Titel:

**Controleer je online zichtbaarheid**

Knoppen:

* website check
* lokale vindbaarheid
* profiel bekijken

# Replit bouwprompt (copy paste)

Gebruik dit in Replit:

```
Build a web platform called OpenRegio.

Goal:
Create a transparency toolkit for entrepreneurs to understand regulations and official letters.

Tech stack:
Frontend: React + Vite
Backend: Node + Express
Database: SQLite

User roles:
Basic user
Pro user

Basic users can:
- view regulation updates
- read knowledge articles
- view example document analyses
- see regional updates

Pro users can:
- upload documents
- run document analysis
- generate information request letters
- use RegioBot
- store documents

Dashboard must show 4 simple blocks:

1. Regional Rules
Show updates and regulatory changes.

2. Understand a Letter
Show example analysis of official letters.

3. Ask RegioBot
Question input for regulations.

4. Website Visibility
Check website presence and local visibility.

Document analysis structure:
- Sender
- Document type
- Legal basis
- Authority
- Deadline
- Recommended action

Routes:

/dashboard
/regulations
/knowledge
/tools/document-analysis
/tools/request-information
/documents
/visibility
/account

Basic users can view information.
Pro users can upload and use tools.
```

# Eén cruciale tip

Je dashboard moet altijd voelen als:

**een controlepaneel voor regelgeving.**

Niet:

* sociaal netwerk
* community
* forum

Maar:

```
regels
brieven
documenten
actie
```
