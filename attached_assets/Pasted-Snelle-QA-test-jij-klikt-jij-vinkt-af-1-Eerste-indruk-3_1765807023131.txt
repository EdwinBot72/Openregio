Snelle QA-test (jij klikt, jij vinkt af)
1) Eerste indruk (30 sec test)

Snap ik binnen 10 seconden wat OpenRegio is?

Zie ik 1 duidelijke knop: “Doe mee / Maak profiel”

Zie ik géén ruis: geen feed, geen bla-bla

Als dit niet klopt: homepage copy + layout fixen, niet meer code bouwen.

2) Login / testaccount

Login werkt zonder errors

Na login land ik op Dashboard (niet op een lege pagina)

Ik kan altijd uitloggen

Als dit hapert: auth + redirects eerst fixen (topprio).

3) Dashboard = “vandaag”

Op dashboard wil ik zien:

“Wat kan ik nu doen?” (3 knoppen max)

Mijn profielstatus (compleet/niet compleet)

Netwerk-snelkoppeling (“ondernemers in mijn regio”)

Als dashboard leeg is: je mist je “digitale werkbank” gevoel.

4) Bedrijfsprofiel

Profiel bewerken is makkelijk (max 1 scherm)

Regio staat duidelijk

Contactgegevens zijn zichtbaar/aanpasbaar

Must: telefoon/website/openingstijden (minimaal).

5) Privacy & Gegevens

Er is een pagina die in normaal Nederlands zegt wat je opslaat

“We verkopen geen data / geen ads” staat er hard in

Export/verwijder hoeft nog niet, maar uitleg wel

6) Zichtbaarheidsbeheer (PRO)

Bestaat als menu-item (liefst “PRO” label)

Als ik geen PRO ben: duidelijke upsell, geen error

Als ik wel PRO ben: per veld dropdowns (PUBLIC/MEMBERS/REGION_ONLY/PRIVATE)

7) Netwerk

Ik zie ondernemers in mijn regio (desnoods dummy data)

Ik kan iemand “bellen” (tel: link) of bericht sturen

Geen social feed nodig; lijst is genoeg

8) RegioBot

1 simpele input + antwoord

3 voorgestelde vragen (“Stroomuitval?”, “Pin stuk?”, “Tekst voor actie?”)

Wat er meestal nog mist bij jouw type platform

(als ik puur kijk naar wat ondernemers verwachten)

Onboarding (3 vragen)

Dashboard dat rust geeft (niet leeg)

Netwerk als bel-lijst (niet als community-feed)

Privacy-pagina die vertrouwen geeft

Eerlijke PRO-afbakening (wat zit in €19,95, wat niet)

Maak het wél testbaar voor mij (snelste route)
