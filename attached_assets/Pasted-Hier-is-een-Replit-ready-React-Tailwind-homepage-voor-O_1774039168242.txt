Voor Tailwind in Replit/Vite heb je deze stack nodig:

```bash
npm create vite@latest openregio -- --template react
cd openregio
npm install
npm install -D tailwindcss @tailwindcss/vite
```

En in `src/index.css`:

```css
@import "tailwindcss";
body {
  margin: 0;
  font-family: Inter, system-ui, sans-serif;
}
* {
  box-sizing: border-box;
}
html {
  scroll-behavior: smooth;
}
```
