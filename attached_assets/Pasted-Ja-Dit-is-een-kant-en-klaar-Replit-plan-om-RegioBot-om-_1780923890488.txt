# Replit Plan — RegioBot als AI-routeplanner voor ondernemers

## Doel

Bouw RegioBot om naar een praktische AI-assistent voor lokale ondernemers.

RegioBot moet niet alleen antwoorden geven, maar ondernemers helpen bepalen:

```txt
wat ze zoeken
welk probleem daarachter zit
welke slimme route ze moeten volgen
welke AI-tools of digitale tools passen
welke template/tekst ze direct kunnen gebruiken
wat OpenRegio eventueel voor ze kan uitvoeren
```

RegioBot wordt dus:

> **De slimme routeplanner voor ondernemers die geen zin hebben om zelf 100 AI-tools uit te zoeken.**

# 5. Nieuwe RegioBot system prompt

Plaats deze prompt als centrale prompt voor RegioBot.

```txt
Je bent RegioBot, een praktische AI-routeplanner voor lokale ondernemers in Nederland.

Je taak is niet alleen antwoord geven. Je helpt ondernemers ontdekken wat ze echt zoeken en welke oplossing daarbij past.

Je helpt met:
- klanten krijgen
- administratie verminderen
- AI-tools kiezen
- automatisering
- teksten en klantcommunicatie
- offertes en facturen
- website en aanbod verbeteren
- social media en content
- lokale acties en campagnes
- planning en organisatie
- gemeentevragen, vergunningen en regels
- verkoop en lancering

Bij elke vraag doe je dit:

1. Herken wat de ondernemer echt probeert op te lossen.
2. Kies één duidelijke categorie.
3. Geef een korte diagnose in gewone taal.
4. Geef een praktische route in maximaal 5 stappen.
5. Adviseer maximaal 3 tot 5 tools die hierbij passen.
6. Geef een direct bruikbaar voorbeeld, template of tekst.
7. Sluit af met een concrete vervolgstap.
8. Noem waar OpenRegio kan helpen als uitvoerende dienst.

Je bent praktisch, nuchter, zakelijk, lokaal en actiegericht.

Je geeft geen definitief juridisch advies. Bij gemeente-, vergunning- of regelvragen geef je een praktische checkroute en voorbeeldvragen die de ondernemer kan stellen.

Antwoord altijd in het Nederlands.

Gebruik deze vaste structuur:

## Wat je eigenlijk zoekt
Leg in 1 of 2 zinnen uit wat de ondernemer nodig heeft.

## Slimme route
Geef 3 tot 5 concrete stappen.

## Handige tools
Noem maximaal 5 tools met korte uitleg.

## Direct bruikbaar
Geef een voorbeeldtekst, checklist, actie of template.

## Vervolgstap
Geef één duidelijke volgende actie en verwijs subtiel naar OpenRegio als dat logisch is.
```

```ts
export type RegioBotIntent =
  | "klanten_krijgen"
  | "administratie_verminderen"
  | "ai_tool_kiezen"
  | "automatisering"
  | "teksten_en_communicatie"
  | "website_en_aanbod"
  | "social_media_en_content"
  | "offertes_en_facturen"
  | "planning_en_productiviteit"
  | "gemeente_en_regels"
  | "verkoop_en_lancering"
  | "bedrijf_organiseren"
  | "onbekend";

export function detectRegioBotIntent(input: string): RegioBotIntent {
  const text = input.toLowerCase();

  if (containsAny(text, ["meer klanten", "klanten krijgen", "omzet", "boekingen", "leads", "nieuwe klanten"])) {
    return "klanten_krijgen";
  }

  if (containsAny(text, ["administratie", "bonnen", "facturen", "boekhouding", "papierwerk"])) {
    return "administratie_verminderen";
  }

  if (containsAny(text, ["welke ai", "ai gebruiken", "ai tool", "chatgpt", "tools", "welke tool"])) {
    return "ai_tool_kiezen";
  }

  if (containsAny(text, ["automatiseren", "workflow", "zapier", "make", "koppelen", "automatisch"])) {
    return "automatisering";
  }

  if (containsAny(text, ["mail", "tekst", "brief", "klacht", "reactie", "review", "bericht"])) {
    return "teksten_en_communicatie";
  }

  if (containsAny(text, ["website", "homepage", "aanbod", "landingspagina", "seo", "vindbaarheid"])) {
    return "website_en_aanbod";
  }

  if (containsAny(text, ["instagram", "facebook", "social", "post", "content", "video", "reel"])) {
    return "social_media_en_content";
  }

  if (containsAny(text, ["offerte", "factuur", "prijsvoorstel", "aanbetaling", "betaling"])) {
    return "offertes_en_facturen";
  }

  if (containsAny(text, ["planning", "taken", "agenda", "overzicht", "productiviteit"])) {
    return "planning_en_productiviteit";
  }

  if (containsAny(text, ["gemeente", "vergunning", "regels", "apv", "stoepbord", "terras", "reclamebord"])) {
    return "gemeente_en_regels";
  }

  if (containsAny(text, ["lanceren", "verkopen", "actie", "campagne", "aanbieding", "betaallink"])) {
    return "verkoop_en_lancering";
  }

  if (containsAny(text, ["organiseren", "structuur", "bedrijf opzetten", "proces", "systeem"])) {
    return "bedrijf_organiseren";
  }

  return "onbekend";
}

function containsAny(text: string, keywords: string[]): boolean {
  return keywords.some((keyword) => text.includes(keyword));
}
```

```ts
export function getToolsForIntent(intent: RegioBotIntent) {
  const toolNamesByIntent: Record<RegioBotIntent, string[]> = {
    klanten_krijgen: ["Google Bedrijfsprofiel", "Canva", "ChatGPT", "Brevo"],
    administratie_verminderen: ["Moneybird", "Google Forms", "ChatGPT", "Make"],
    ai_tool_kiezen: ["ChatGPT", "Canva", "Make", "Trello", "Google Forms"],
    automatisering: ["Make", "Google Forms", "Moneybird", "Brevo"],
    teksten_en_communicatie: ["ChatGPT", "Canva"],
    website_en_aanbod: ["ChatGPT", "Google Bedrijfsprofiel", "Canva"],
    social_media_en_content: ["Canva", "CapCut", "ChatGPT", "Google Bedrijfsprofiel"],
    offertes_en_facturen: ["Moneybird", "ChatGPT", "Google Forms"],
    planning_en_productiviteit: ["Trello", "Google Forms", "ChatGPT"],
    gemeente_en_regels: ["ChatGPT", "Google Forms"],
    verkoop_en_lancering: ["Canva", "ChatGPT", "Mollie", "Brevo"],
    bedrijf_organiseren: ["Trello", "Google Forms", "Make", "ChatGPT"],
    onbekend: ["ChatGPT", "Canva", "Google Forms"]
  };

  const names = toolNamesByIntent[intent];

  return businessTools.filter((tool) => names.includes(tool.name));
}
```

```ts
app.post("/api/regiobot/route", async (req, res) => {
  try {
    const { message, businessType, city } = req.body;

    if (!message || typeof message !== "string") {
      return res.status(400).json({ error: "Bericht ontbreekt." });
    }

    const intent = detectRegioBotIntent(message);
    const tools = getToolsForIntent(intent);

    const prompt = buildRegioBotPrompt({
      message,
      businessType,
      city,
      intent,
      tools
    });

    const answer = await generateAiAnswer(prompt);

    return res.json({
      intent,
      tools,
      answer
    });
  } catch (error) {
    console.error("RegioBot route error:", error);
    return res.status(500).json({ error: "RegioBot kon geen route maken." });
  }
});
```

# 10. Prompt builder


## Code

```ts
import type { BusinessTool } from "../data/regiobot-tools";
import type { RegioBotIntent } from "./regiobot-intent";

interface BuildRegioBotPromptInput {
  message: string;
  businessType?: string;
  city?: string;
  intent: RegioBotIntent;
  tools: BusinessTool[];
}

export function buildRegioBotPrompt(input: BuildRegioBotPromptInput): string {
  const { message, businessType, city, intent, tools } = input;

  const toolList = tools
    .map((tool) => {
      return `- ${tool.name}: ${tool.whenToUse} OpenRegio-koppeling: ${tool.openRegioService || "Geen specifieke koppeling."}`;
    })
    .join("\n");

  return `
Je bent RegioBot, een praktische AI-routeplanner voor lokale ondernemers in Nederland.

Context:
- Bedrijfstype: ${businessType || "niet opgegeven"}
- Plaats/regio: ${city || "niet opgegeven"}
- Herkende categorie: ${intent}

Vraag van ondernemer:
"${message}"

Aanbevolen tools:
${toolList}

Maak een antwoord in deze vaste structuur:

## Wat je eigenlijk zoekt
Leg kort uit wat de ondernemer probeert op te lossen.

## Slimme route
Geef 3 tot 5 concrete stappen. Maak het praktisch en direct uitvoerbaar.

## Handige tools
Noem maximaal 5 tools uit de aanbevolen tools. Leg per tool in 1 zin uit waarvoor die handig is.

## Direct bruikbaar
Geef een voorbeeldtekst, checklist, social post, mail, campagne-idee, workflow of template die direct gebruikt kan worden.

## Vervolgstap
Geef 1 concrete volgende actie. Verwijs waar logisch naar OpenRegio als uitvoerende hulp.

Regels:
- Antwoord in het Nederlands.
- Wees duidelijk, praktisch en zakelijk.
- Geen lange theorie.
- Geen definitief juridisch advies.
- Bij gemeentevragen: geef checkroute en voorbeeldvragen.
`;
}
```

# 20. Eindbeeld

RegioBot wordt geen losse chatbot, maar een **AI-startpunt voor ondernemersvragen**.

De kern:

```txt
Ondernemer heeft vraag
↓
RegioBot snapt probleem
↓
RegioBot geeft slimme route
↓
RegioBot adviseert tools
↓
RegioBot geeft template
↓
OpenRegio biedt uitvoering
```

Dat is sterk, logisch en verkoopbaar.
