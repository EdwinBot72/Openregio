Ja. Je hebt de **Basischeck UI al** (`client/src/pages/basischeck.tsx`), maar hij **slaat niks op** en je dashboard gebruikt **hardcoded score**. Dus je moet 3 dingen doen in Replit:

1. **DB velden toevoegen**
2. **API endpoint om op te slaan**
3. **Dashboard + Basischeck page koppelen**

Hier is de checklist + exact waar je moet zitten.

---

## 0) Open Replit project

In Replit: upload / open je repo → run `npm install` (1x) → daarna `npm run dev`.

---

## 1) DB: voeg Basischeck velden toe

**Bestand:** `shared/schema.ts`
Zoek `bedrijfsprofielen` en voeg deze kolommen toe:

```ts
// in shared/schema.ts bij bedrijfsprofielen:
cashMogelijk: boolean("cash_mogelijk").notNull().default(false),
bonnenblok: boolean("bonnenblok").notNull().default(false),
papierenTelefoonlijst: boolean("papieren_telefoonlijst").notNull().default(false),
offlineWerken: boolean("offline_werken").notNull().default(false),
noodstroom: boolean("noodstroom").notNull().default(false),
basischeckIngevuld: boolean("basischeck_ingevuld").notNull().default(false),
```

Daarna push je schema:

```bash
npm run db:push
```

> Als dit faalt: check of je `DATABASE_URL` goed staat in Replit Secrets.

---

## 2) API: endpoint om basischeck op te slaan

Je hebt al `/api/business-profile` endpoints.
We voegen een extra route toe (cleaner), bv:

**Bestand:** `server/routes.ts`
Plak onder “Business Profile routes”:

```ts
app.post("/api/basischeck", async (req, res) => {
  try {
    if (!req.user?.id) return res.status(401).json({ error: "Niet ingelogd" });

    const profiel = await storage.getBedrijfsprofielByUserId(req.user.id);
    if (!profiel) return res.status(404).json({ error: "Bedrijfsprofiel niet gevonden" });

    const { cash, bonnenblok, telefoonlijst, noodstroom, offline } = req.body ?? {};

    const updated = await storage.updateBedrijfsprofiel(profiel.id, {
      cashMogelijk: !!cash,
      bonnenblok: !!bonnenblok,
      papierenTelefoonlijst: !!telefoonlijst,
      noodstroom: !!noodstroom,
      offlineWerken: !!offline,
      basischeckIngevuld: true,
    });

    res.json(updated);
  } catch (e) {
    console.error(e);
    res.status(500).json({ error: "Fout bij opslaan basischeck" });
  }
});
```

## 3) Storage: zorg dat updateBedrijfsprofiel die velden accepteert

Jouw `server/storage.ts` heeft een `updateBedrijfsprofiel(...)` die nu gewoon spread doet.
Dat is top — **maar** je `createBedrijfsprofiel` zet de nieuwe velden nog niet.
Fix dat snel:

**Bestand:** `server/storage.ts`
In `createBedrijfsprofiel(...)` zet defaults:

```ts
cashMogelijk: false,
bonnenblok: false,
papierenTelefoonlijst: false,
offlineWerken: false,
noodstroom: false,
basischeckIngevuld: false,
```

(als je types zeuren: voeg ze ook toe aan je `Bedrijfsprofiel` type in `shared/schema.ts` types export — maar meestal pakt TS dit vanzelf als je het schema update.)

---

## 4) Basischeck page: stuur resultaat naar API

**Bestand:** `client/src/pages/basischeck.tsx`

In het “finished” stuk (results page) voeg je een save-call toe. Simpel:

* import `apiRequest` (waarschijnlijk in `client/src/lib/queryClient`)

```ts
import { apiRequest } from "@/lib/queryClient";
import { useQueryClient } from "@tanstack/react-query";
```

Dan: zodra `finished === true`, knop “Opslaan” of meteen auto-save.

Snelste: knop.

```ts
const queryClient = useQueryClient();

const saveBasischeck = async () => {
  await apiRequest("POST", "/api/basischeck", {
    cash: !!answers.cash,
    bonnenblok: !!answers.bonnenblok,
    telefoonlijst: !!answers.telefoonlijst,
    noodstroom: !!answers.noodstroom,
    offline: !!answers.offline,
  });
  queryClient.invalidateQueries({ queryKey: ["/api/business-profile/me"] });
};
```

En op je results page:

```tsx
<Button onClick={saveBasischeck}>Sla op in mijn profiel</Button>
```

## 5) Dashboard: stop met hardcoded score

**Bestand:** `client/src/pages/dashboard.tsx`

Je doet nu:

```ts
const basischeckScore = 3;
```

Vervang dat met echte data uit `bedrijfsprofiel`:

```ts
const basischeckScore = [
  bedrijfsprofiel?.cashMogelijk,
  bedrijfsprofiel?.bonnenblok,
  bedrijfsprofiel?.papierenTelefoonlijst,
  bedrijfsprofiel?.offlineWerken,
  bedrijfsprofiel?.noodstroom,
].filter(Boolean).length;

const basischeckDone = !!bedrijfsprofiel?.basischeckIngevuld;
```

En toon echte statusregels.
