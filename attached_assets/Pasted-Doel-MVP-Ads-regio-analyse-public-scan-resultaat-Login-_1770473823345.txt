4) Voeg localStorage opslag toe (zodat scans “blijven”)

File: client/src/pages/regio-analyse.tsx

A) Helpers bovenin
const STORAGE_KEY = "openregio_regioanalyse_v1";

type SavedState = {
  answers: Record<string, number>;
  currentQ: number;
  region?: string;
  sector?: string;
  savedAt: number;
};

function loadSaved(): SavedState | null {
  try {
    const raw = localStorage.getItem(STORAGE_KEY);
    return raw ? (JSON.parse(raw) as SavedState) : null;
  } catch {
    return null;
  }
}

function saveState(state: SavedState) {
  try {
    localStorage.setItem(STORAGE_KEY, JSON.stringify(state));
  } catch {}
}

B) Bij mount: load

Onder je state hooks (na useState), voeg toe:

useEffect(() => {
  const saved = loadSaved();
  if (!saved) return;

  // optioneel: expire na 7 dagen
  const ageMs = Date.now() - saved.savedAt;
  if (ageMs > 7 * 24 * 60 * 60 * 1000) return;

  setAnswers(saved.answers || {});
  setCurrentQ(saved.currentQ || 0);
  // als je region/sector hebt:
  // setRegion(saved.region || "");
  // setSector(saved.sector || "");
}, []);

C) Na elke answer: save

In je handleAnswer(questionKey, value) (of waar je answers zet), voeg na setAnswers toe:

setAnswers((prev) => {
  const next = { ...prev, [questionKey]: value };
  saveState({
    answers: next,
    currentQ: Math.min(currentQ + 1, QUESTIONS.length - 1),
    savedAt: Date.now(),
  });
  return next;
});


Belangrijk: dit gebruikt nog currentQ in save. Wil je 100% clean? Dan save je in een useEffect op answers/currentQ. Simpler is ok voor MVP.

D) Reset-knop (handig)

Zet op resultaatpagina of in header een kleine “reset”:

function resetScan() {
  localStorage.removeItem(STORAGE_KEY);
  setAnswers({});
  setCurrentQ(0);
}
